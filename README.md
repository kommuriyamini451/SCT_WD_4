# 📝 Advanced To-Do List App - SCT_WD_4

Feature-rich To-Do List application built as Task 4 for **SkillCraft Technology** Web Development Internship.

### 🔗 Live Demo
**https://kommuriyamini451.github.io/SCT_WD_4/**

## ✨ Features
- **Add Tasks** - Task name, date & time, priority level
- **Priority System** - High 🔴 / Medium 🟠 / Low 🟢 with color coding
- **Mark Complete** - Toggle tasks as complete/pending
- **Edit & Delete** - Update or remove tasks with confirmation
- **Search Tasks** - Live search by task name
- **Filter Tasks** - All / Completed / Pending views
- **Date & Time Stamp** - Set due date for each task
- **Local Storage** - All tasks persist after page refresh
- **Task Counter** - Shows total tasks vs completed tasks
- **Modern UI** - Purple gradient background + glassmorphism card
- **Responsive Design** - Works on mobile, tablet & desktop

## 🛠️ Tech Stack
- **HTML5** - Semantic structure
- **CSS3** - Flexbox, Gradients, Animations, Custom fonts
- **JavaScript** - DOM manipulation, LocalStorage API, Array methods
- **Google Fonts** - Poppins font family

## 📚 What I Learned
- `localStorage` for saving data in browser
- `JSON.parse()` & `JSON.stringify()` for data persistence
- Array methods: `filter()`, `forEach()`, `splice()`
- `datetime-local` input for date & time selection
- Dynamic rendering with `createElement` & `innerHTML`
- Search & filter logic using multiple conditions
- `prompt()` and `confirm()` for edit/delete actions
- CSS priority borders + conditional styling

## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/kommuriyamini451/SCT_WD_4.git`
2. Open `index.html` in your browser
3. Add tasks and test all features
